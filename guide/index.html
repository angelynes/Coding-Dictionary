How to use this dictionary

Colour legend

Section titled “Colour legend”
  • value you choose
  • CODE type as is
  • concept an idea
  • keyword built in

The colours are the same as in the original Google Docs. Inside a dictionary, the key sits at the bottom of the sidebar.

  • Value: something you choose, like a table name, a variable or a number.
  • CODE: the code you type exactly as written.
  • CONCEPT: the word for an idea or definition.
  • keyword: a built-in Python keyword such as break or True.

Entries

Section titled “Entries”

Each term is an entry: one row with the term and a short meaning for quick lookup. Click the row to open the full explanation and the code.

Keep short under about 40 characters.

Example entry

Short meaning for quick lookup

SELECT picks columns. * means every column.

Runnable code

Section titled “Runnable code”

Add the word run after the language of any code block and it becomes an editable box with a ▶ Run button (or press ⌘/Ctrl + Enter):

Without run, it stays a normal highlighted code block. Python runs with Pyodide and SQL runs on SQLite with the sample database, both inside your browser.

Editing on the live site

Section titled “Editing on the live site”

On the-coding-dictionary.vercel.app you can add and change notes without opening the code:

  1. Scroll to the bottom of any page and click Sign in to edit (only the owner’s GitHub account is allowed).
  2. Use + New term (bottom right, or at the top of a topic), the pencil on a term, + New topic in the sidebar, or + Add a language on the home page.
  3. Click Save. The change is saved to GitHub and the site updates in about a minute.
