Matplotlib

Section titled “Matplotlib”

Builds graphs such as line plots, scatter plots and histograms. Always start with:

Use help(plt.hist) or help(plt.plot) to read the help for any function.

Line plot · plt.plot()

Draw a line chart

Builds the line plot. x is the horizontal axis, y the vertical axis. plt.show() displays it.

Scatter plot · plt.scatter()

Draw a dot chart

Builds the scatter plot. plt.xscale('log') puts the x-axis on a logarithmic scale.

Histogram · plt.hist()

Draw a histogram (bins = bars)

Bins = the number of bars. By default Python uses 10. plt.clf() cleans the plot.

Customisation

Section titled “Customisation”
Code What it does
plt.xlabel('year') Label the x-axis
plt.ylabel('age') Label the y-axis
plt.title('progress') Title of the graph
plt.xticks([0, 1, 2], ['one', 'two', 'three']) Replace tick values on the x-axis
plt.yticks(previous, after) Replace tick values on the y-axis
plt.scatter(x, y, c=col) c = colour
plt.scatter(x, y, s=size) s = size of the dots
plt.scatter(x, y, alpha=0.8) Transparency: 0 invisible, 1 solid
plt.text(1550, 71, 'India') Add text into the plot
plt.grid(True) Add a grid
