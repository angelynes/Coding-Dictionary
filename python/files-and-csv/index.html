Files & CSV

Text files (.txt)

Section titled “Text files (.txt)”

open() · read() · readlines()

Open a file; read all or by line
  • .read() gives one big string.
  • .readlines() gives a list, one item per line.
  • Looping over the file reads line by line.

Writing: write() or print(file=)

Write text into a file

The 'w' sets it to write mode. Use f.close() to close the file when you’re done.

with open(...) as …

Open a file; closes automatically

The safest way: the file is closed automatically at the end of the block.

CSV: Comma Separated Values

Section titled “CSV: Comma Separated Values”

csv.reader

Read CSV rows as lists

Each row comes back as a list.

delimiter=

Use another separator than comma

Use another character instead of a comma.

csv.DictReader

Read CSV rows as dictionaries

Each row becomes a dictionary, using the first line as the keys.

🐍 Pythoneditable · ⌘/Ctrl + Enter to run

csv.writer · csv.DictWriter

Write rows as lists / dicts
  • csv.writer writes lists as rows.
  • csv.DictWriter writes dictionaries. fieldnames sets the column order.
