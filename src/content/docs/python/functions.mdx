    a: Ends the function and gives the result back to the caller.

    a: The value you pass into a function, e.g. `hello` in `def name(hello):`

<Entry term="def">
<Fragment slot="code">

```python
def greet(name):
    print('Hello', name)

greet('Angel')
```

</Fragment>

Creates a function.

- `greet`: the <Value>function name</Value>
- `name`: the <Concept>argument</Concept> (input)

</Entry>

<Entry term="return">
<Fragment slot="code">

```python
def add(x, y):
    return x + y

total = add(2, 3)   # 5
```

</Fragment>

`return` **ends** the running function and **gives the result back** to the caller, so you can store it in a variable.

</Entry>

```python run
def add(x, y):
    return x + y

def describe(n):
    if n % 2 == 0:
        return 'even'
    return 'odd'

print(add(2, 3))
print(describe(7), describe(10))
print(abs(-4.5))
```
