import { Value, Concept, Entry } from '@components';

A <Concept>dictionary</Concept> stores **key: value** pairs (words with definitions), e.g. `{'a': 'apple', 'b': 'blueberry', 'c': 'carrot'}`.

## Reading & changing

<Entry term="Taking values">
<Fragment slot="code">

```python
dictionary['a']   # 'apple'
```

</Fragment>

Look up a value by its <Value>key</Value>.

</Entry>

<Entry term="Adding / changing a definition">
<Fragment slot="code">

```python
dictionary['a'] = 'ant'      # change
dictionary['d'] = 'durian'   # add
```

</Fragment>

The same syntax **changes** an existing key or **adds** a new one.

</Entry>

<Entry term="get()">
<Fragment slot="code">

```python
fruit = dictionary.get('z', 'unknown')
```

</Fragment>

Returns the value, or a <Value>default</Value> when the key isn't in the dictionary, instead of crashing.

</Entry>

<Entry term="update()">
<Fragment slot="code">

```python
dictionary1.update(dictionary2)
```

</Fragment>

Adds more keys, or changes the definition of existing ones, using another dictionary.

</Entry>

<Entry term="Splitting and defining">
<Fragment slot="code">

```python
line = 'Angel 91234567'
name, number = line.split()
phonebook[name] = number
```

</Fragment>

Split an input into parts and store them as `{name: number}`.

</Entry>

## Looping

| Code | Gives |
| --- | --- |
| `for key in dictionary:` | Each key |
| `dictionary.values()` | Each value |
| `dictionary.items()` | Each pair, e.g. `('a', 'apple')` |

```python run
food = {'a': 'apple', 'b': 'blueberry', 'c': 'carrot'}
food['a'] = 'ant'
food['d'] = 'durian'
print(food.get('z', 'not found'))

for key, value in food.items():
    print(key, '->', value)
```
