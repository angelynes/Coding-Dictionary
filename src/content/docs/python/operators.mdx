## Maths

| Symbol | Meaning | Example | Result |
| --- | --- | --- | --- |
| `+` | Addition | `5 + 2` | `7` |
| `-` | Subtraction | `5 - 2` | `3` |
| `*` | Multiplication | `5 * 2` | `10` |
| `/` | Division | `5 / 2` | `2.5` |
| `//` | Floor division (whole number part) | `5 // 2` | `2` |
| `**` | Power of | `5 ** 2` | `25` |
| `%` | Remainder from division | `5 % 2` | `1` |

## Comparisons

Comparisons give a <Concept>Boolean</Concept> result: `True` or `False`.

| Symbol | Meaning |
| --- | --- |
| `==` | Equal to |
| `!=` | Not equal to |
| `<` | Less than |
| `<=` | Less than or equal to |
| `>` | More than |
| `>=` | More than or equal to |

```python run
print(5 + 2, 5 - 2, 5 * 2, 5 / 2)
print(5 // 2, 5 ** 2, 5 % 2)
print(5 == 2, 5 != 2, 5 > 2, 5 <= 2)
```

:::tip
`%` is handy for checking even or odd numbers: `number % 2 == 0` means the number is even.
:::
