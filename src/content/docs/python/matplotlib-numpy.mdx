## Matplotlib

Builds graphs such as line plots, scatter plots and histograms. Always start with:

```python
import matplotlib.pyplot as plt
```

Use `help(plt.hist)` or `help(plt.plot)` to read the help for any function.

<Entry term="Line plot · plt.plot()" short="Draw a line chart">
<Fragment slot="code">

```python
plt.plot(x, y)
plt.show()
```

</Fragment>

Builds the line plot. `x` is the horizontal axis, `y` the vertical axis. `plt.show()` displays it.

</Entry>

<Entry term="Scatter plot · plt.scatter()" short="Draw a dot chart">
<Fragment slot="code">

```python
plt.scatter(x, y)
plt.xscale('log')
plt.show()
```

</Fragment>

Builds the scatter plot. `plt.xscale('log')` puts the x-axis on a <Concept>logarithmic scale</Concept>.

</Entry>

<Entry term="Histogram · plt.hist()" short="Draw a histogram (bins = bars)">
<Fragment slot="code">

```python
plt.hist(values, bins=5)
plt.show()
plt.clf()
```

</Fragment>

<Concept>Bins</Concept> = the number of bars. By default Python uses 10. `plt.clf()` cleans the plot.

</Entry>

## Customisation

| Code | What it does |
| --- | --- |
| `plt.xlabel('year')` | Label the x-axis |
| `plt.ylabel('age')` | Label the y-axis |
| `plt.title('progress')` | Title of the graph |
| `plt.xticks([0, 1, 2], ['one', 'two', 'three'])` | Replace tick values on the x-axis |
| `plt.yticks(previous, after)` | Replace tick values on the y-axis |
| `plt.scatter(x, y, c=col)` | `c` = colour |
| `plt.scatter(x, y, s=size)` | `s` = size of the dots |
| `plt.scatter(x, y, alpha=0.8)` | Transparency: 0 invisible, 1 solid |
| `plt.text(1550, 71, 'India')` | Add text into the plot |
| `plt.grid(True)` | Add a grid |

<Entry term="Colour by category" short="Colour dots by group with a dict">
<Fragment slot="code">

```python
dict = {
    'Asia': 'red',
    'Europe': 'green',
    'Africa': 'blue',
    'Americas': 'yellow',
    'Oceania': 'black',
}
col = [dict[c] for c in continent]
plt.scatter(gdp, life, c=col, alpha=0.8)
```

</Fragment>

The Gapminder data has a list `continent` with the continent each country belongs to. A dictionary maps each continent to a colour.

</Entry>

## NumPy

<Entry term="np.array()" short="List where maths hits every item">
<Fragment slot="code">

```python
import numpy as np
np_pop = np.array(pop)
np_pop = np_pop * 2
plt.scatter(gdp, life, s=np_pop)
```

</Fragment>

Stores a list as a <Concept>NumPy array</Concept>. Maths works **on every element**: `* 2` doubles each value. Here the array sets the dot sizes.

</Entry>

```python run title="Python + NumPy"
import numpy as np
pop = [1.2, 3.5, 0.8]
print([p * 2 for p in pop])   # list: loop needed
print(np.array(pop) * 2)      # array: maths on every element
```
