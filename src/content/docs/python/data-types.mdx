## Printing words & phrases

<Entry term="Joining with , vs +">
<Fragment slot="code">

```python
print('I am', 20, 'years old')   # comma
print('Hello' + 'World')         # plus
```

</Fragment>

- `,` includes **one space** and works with numbers and strings.
- `+` includes **no space** and only joins strings.

</Entry>

<Entry term="sep= and end=">
<Fragment slot="code">

```python
print('a', 'b', 'c', sep='-')    # a-b-c
print('Loading', end='...')
print('done')                    # Loading...done
```

</Fragment>

- `sep=` sets what goes **between** items (default `' '`).
- `end=` sets what goes at the **end** (default is a new line).

</Entry>

## Changing data type

<Entry term="str() · int() · float()">
<Fragment slot="code">

```python
str(variable)     # to String
int(variable)     # to Integer
float(variable)   # to Float
```

</Fragment>

Converts a value to another type. Useful because `input()` always gives a **string**.

</Entry>

<Entry term="round()">
<Fragment slot="code">

```python
round(3.7)       # 4
round(3.14159, 2)  # 3.14
```

</Fragment>

Rounds a float to the **nearest** whole number, or to a number of decimal places.

:::note[Corrected from my notes]
It's written `round(variable)`, not `variable.round()`. It rounds to the nearest number, not always up.
:::

</Entry>

```python run
age = '20'
print(age + '1')        # joins text: 201
print(int(age) + 1)     # maths: 21
print(float(age))       # 20.0
print(round(2.567, 1))  # 2.6
```

## Changing data type (Unicode)

<Entry term="ord() · chr()">
<Fragment slot="code">

```python
ord('a')   # 97
chr(97)    # 'a'
```

</Fragment>

- `ord` (ordinal) changes **letters to numbers**.
- `chr` (character) changes **numbers to letters**.

</Entry>

## Binary and decimals

| Binary | Decimal |
| --- | --- |
| Base 2 | Base 10 |
| Series of 0s and 1s | Numbers from 0 to 9 |

```python run
print(bin(10))         # decimal to binary: 0b1010
print(int('1010', 2))   # binary to decimal: 10
```
