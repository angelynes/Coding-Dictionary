## Colour legend

<Legend />

The colours are the same as in the original Google Docs. Inside a dictionary, the key sits at the bottom of the sidebar.

- <Value>Value</Value>: something **you** choose, like a table name, a variable or a number.
- `CODE`: the code you type exactly as written.
- <Concept>CONCEPT</Concept>: the word for an idea or definition.
- <Keyword>keyword</Keyword>: a built-in Python keyword such as <Keyword>break</Keyword> or <Keyword>True</Keyword>.

## Entries

Each term is an **entry**: one row with the term and a **short meaning** for quick lookup. Click the row to open the full explanation and the code.

Keep `short` under about 40 characters.

<Entry term="Example entry" short="Short meaning for quick lookup" open>
<Fragment slot="code">

```sql
SELECT * FROM celebs;
```

</Fragment>

<Concept>SELECT</Concept> picks columns. `*` means every column.

</Entry>

## Runnable code

Add the word `run` after the language of any code block and it becomes an editable box with a **▶ Run** button (or press <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>Enter</kbd>):

````md
```python run
print('Hello!')
```

```sql run
SELECT * FROM celebs;
```
````

Without `run`, it stays a normal highlighted code block. Python runs with [Pyodide](https://pyodide.org) and SQL runs on SQLite with the [sample database](../sql/sample-database/), both inside your browser.

```python run
name = 'Angel'
print('Hello,', name + '!')
```

```sql run
SELECT name, age FROM celebs WHERE age > 30;
```

## Adding notes after class

<Steps>

1. Open a terminal in the project folder and run:

   ```bash
   npm run new -- python "List comprehensions"
   ```

   This creates `src/content/docs/python/list-comprehensions.mdx` from a template and adds it to the sidebar.

2. Run `npm run dev` and open http://localhost:4321 to see your page update as you type.

3. Fill in the entries: a term, a short meaning, the full explanation and the code.

</Steps>

<FileTree>
- src/
  - content/docs/
    - python/ one file per topic
    - sql/
  - data/sample-db.sql the tables used by runnable SQL boxes
  - components/ Entry, RunPython, RunSQL…
- astro.config.mjs sidebar order
</FileTree>

## Editing on the live site

On [coding-dictionary-coral.vercel.app](https://coding-dictionary-coral.vercel.app) you can add and change notes without opening the code:

1. Scroll to the bottom of any page and click **Sign in to edit** (only the owner's GitHub account is allowed).
2. Use **+ New term** (bottom right, or at the top of a topic), the **pencil** on a term, **+ New topic** in the sidebar, or **+ Add a language** on the home page.
3. Click **Save**. The change is saved to GitHub and the site updates in about a minute.
